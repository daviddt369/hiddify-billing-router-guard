# Личный кабинет пользователя

Страница, которую пользователь открывает по своей личной ссылке в браузере: тариф, остаток дней и трафика, продление с оплатой ЮKassa (плашки тарифов), инструкция по подключению (приложения по платформам, ссылка подписки и QR, импорт маршрутизации Happ / INCY), временная ссылка на 5 минут, вкладки «Все конфиги», «Telegram Proxy», «DoH». Вместо прежней страницы Hiddify («Home / All Configs / Telegram Proxy / DoH»), в стиле панели V2, на русском, для телефона и компьютера.

## Что это в коде

| Файл | Что |
|---|---|
| `cabinet.py` | собирает данные из панели (пользователь, остаток, тариф `commercial_plan`, подписка, тарифы для оплаты, ссылки) и рисует страницу |
| `cabinet.html` | шаблон (ставится в `panel/user/templates/cabinet/`); данные приходят JSON-ом, страницу рисует браузер |
| `install_cabinet.sh` | бэкап, копирование, **одна** правка `user.py::new()` (кабинет, если нужен; при любой ошибке показывается страница Hiddify), настройки |

Выдача подписок и конфигов (`/sub`, `/auto`, `/xray`, `/happ`, ...) не затронута: приложения получают тот же ответ.

## Настройки (`/opt/hiddify-manager/cabinet/cabinet.json`, читаются при каждом запросе)

| Ключ | Что |
|---|---|
| `enabled` | `true` - кабинет у всех; `false` - только по `?cabinet=1` (предпросмотр) |
| `yookassa_shop_id` | номер магазина ЮKassa для формы оплаты; `"0"` или пусто = оплаты на сайте нет, только кнопка бота |
| `support_url` | ссылка кнопки «Написать в поддержку» (пусто = `support_url` панели, потом `branding_site`) |
| `brand` | название в шапке (пусто = `branding_title` панели) |
| `pay_action` | куда отправляется форма (по умолчанию адрес ЮKassa) |

`?classic=1` всегда показывает прежнюю страницу Hiddify.

## Оплата

Форма отправляется прямо на ЮKassa и несёт те же четыре поля, что обычная форма «своя сумма» из кабинета ЮKassa: `cps_phone`, `customerNumber`, `sum`, `shopId`. **Телефон передаётся ровно так, как введён** (и в `cps_phone`, и в `customerNumber`: по нему платёж находят и зачисляют вручную). Телефон подставляется из имени аккаунта, если оно похоже на телефон. Скрипт ЮKassa на этой странице **не** загружается: тут личная ссылка пользователя, чужой код не нужен (форма без чека делает то же самое без него). Сумма лежит в форме, а не на стороне ЮKassa: при зачислении сверяйте **оплаченную** сумму с ценой тарифа.

## Установка и откат

```bash
bash cabinet/install_cabinet.sh cabinet            # на узле от root: бэкап в /root/cabinet-backup-<время>, enabled=false
# включить для всех: "enabled": true в cabinet.json (перезапуск не нужен)
# откат: cp -a /root/cabinet-backup-<время>/user.py <panel>/panel/user/user.py; rm -rf <panel>/panel/user/cabinet.py <panel>/panel/user/templates/cabinet; systemctl restart hiddify-panel
```

Проверено на стенде (WSL) на пяти аккаунтах: активна, пробный, закончилась, трафик исчерпан, отключена.
