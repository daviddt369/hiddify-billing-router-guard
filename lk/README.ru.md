# lk: страница регистрации пробного доступа (для тех, у кого нет Telegram)

Статическая страница `lk.<домен>` + один вызов API. Заменяет страницу на рабочем сайте владельца (WordPress: защита «решите пример» и прокси `wp-json/vpn/v1/trial`).

## Как это работает

1. **Витрина** (`index.html`): обычная киношная страница «HD Кино» (фильмы и сериалы в HD и 4K) и проверка «решите пример». Пример случайный, ответ ВСЕГДА одно и то же число (задаётся параметром `--gate`, своё выберите сами). До правильного ответа на странице нет ни слова про сервис, ни в тексте, ни в исходнике (это проверяет `install_lk.sh`).
2. После правильного ответа страница подгружает рабочую часть: `app.html` и `app.js`. nginx отдаёт их только с `?k=<это число>`, без него 404. Это защита от случайных сканеров, а не настоящий секрет.
3. Рабочая часть: поле телефона. Страница шлёт `POST /api/trial` на СВОЙ адрес; nginx (`zz-lk.conf`) передаёт запрос на конечную точку панели `/<путь клиента>/api/v2/trial/` и возвращает ответ как есть. Адрес панели браузер не видит.
4. Лимиты: панель — 2 запроса в час с одного адреса (в памяти процесса); nginx — 6 запросов в минуту, всплеск 3. Адрес клиента берётся из соединения (PROXY protocol), заголовки `X-Real-IP` / `X-Forwarded-For` от клиента затираются (проверено подделкой на стенде).
5. После ввода номера страница показывает ссылку подписки, кнопку «Открыть личный кабинет», шаги привязки Telegram (бот подтверждает номер кнопкой «Отправить номер телефона», чужой номер привязать нельзя) и ПОД НИМИ полную инструкцию: приложения по платформам, шаги, смена региона App Store (на iPhone и iPad все три приложения только из App Store США; блок раскрыт по умолчанию на iOS).

Лимиты пробного доступа (дни, ГБ, устройства) берутся из настройки бота (`hutils/tg_texts.trial_settings`), страница их не хранит.

## Установка на ноду

1. DNS: запись A `lk` → IP ноды. Домен `lk.<домен>` добавить в панели (любой режим, например «только ссылка подписки»): панель выпустит и будет продлевать сертификат.
2. На ноде от root: `bash install_lk.sh <хост> <имя бота без @ или -> "<название>" <число>`. Скрипт проверяет сертификат, собирает страницу, ставит блок nginx, проверяет (страница, заголовки, http→https, 405 на GET, 404 на прочее, ответ панели на заведомо неверный номер БЕЗ создания аккаунта, неизменность подписки на основном домене) и при любом провале сам убирает блок.
3. Снять: `bash install_lk.sh --remove`.

## Один источник текстов инструкции

`guide.json` (делает `make_guide.py`): приложения и ссылки, порядок и рекомендация по платформам, шаги, смена региона. Из него собираются страница `lk`, кабинет (`cabinet/apply_guide.py`, `cabinet/make_region_block.py`) и текст бота (правится вручную в `cabinet/bot/instruction.html`, проверяется `bot_menu_test.py`).


**Обложки не входят в репозиторий:** положите свои `assets/cw.webp` (широкая) и `assets/ct.webp` (высокая); без них `install_lk.sh` остановится. Так фронт не привязан к какому-либо конкретному сайту.
