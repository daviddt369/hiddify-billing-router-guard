# CP-09 (необязательный) · DNS первого хопа: DoH через туннель вместо открытых запросов с RU-ноды (закрывает F-03)

**Статус: подготовлено; дизайн доказан на уровне пакетов на стенде; механика (apply/откат/сбой/защита от ручных правок) отрепетирована на копии каталога конфигов первого хопа с настоящим `xray run -test -confdir`. На production НЕ применялось. В список этапа 2 это не входило — оставлено как готовый пакет под отдельное решение владельца.**

## 1. Проблема (подтверждена)

`/opt/hiddify-manager/xray/configs/02_dns.json` (шаблон `.j2` из Hiddify, не менялся с 2026-02-21): серверы `1.1.1.1`, `8.8.8.8`, `localhost`, тег `DNS-Internal`; маршрутизация первого хопа: `domainStrategy: IPOnDemand` и правило №1 `port 53 → DNS-Internal`. Следствие: имена зарубежных сайтов (из TLS-SNI, из DNS-запросов клиентов на порт 53) резолвятся **обычным UDP/53 прямо с интерфейса RU-ноды** — открытым текстом для сети хостера/провайдера. Счётчик outbound `DNS-Internal` за 4,1 суток: ↑6,8 МБ / ↓20,6 МБ.

Доказательство на уровне пакетов (`test/lab-f03-packet-level.txt`; мини-«первый хоп» на настоящем Xray 26.7.28 с той же схемой DNS и тремя подставными резолверами, источник пакета определяется по `sendThrough` выходов):

| Вариант DNS | зарубежное имя | российское имя (`.ru`) |
|---|---|---|
| сейчас (`1.1.1.1`, `8.8.8.8`, `localhost`) | **UDP/53 к «1.1.1.1», отправил САМ узел** — утечка | UDP/53 к «1.1.1.1», отправил сам узел |
| предлагаемый | **DoH TCP/443**, отправил **выход (EXIT-DE)**, то есть запрос прошёл через туннель | UDP/53 к российскому резолверу (Яндекс) напрямую — допустимо |

На проде DoH до 1.1.1.1:443 не попадает под правило №0 (прямо только для адресов самой ноды), поэтому уходит финальным правилом в router → выход (проверено чтением `03_routing.json`).

## 4. Риск прерывания подключений и поведения

* **Перезапуск hiddify-xray:** все клиентские соединения первого хопа обрываются на 1–5 с (на стенде перезапуск занимает 0,2–0,5 с; на проде больше правил и geo-файлов), клиенты переподключаются сами. Делать в минимум нагрузки.
* **Новая зависимость от выходов для зарубежных имён:** DoH идёт через router → выходы. Если оба выхода недоступны, зарубежные имена перестают резолвиться (раньше резолвились напрямую, но дальше трафик всё равно некуда было отправить). Российские имена (`.ru/.su/.рф`) не зависят — резолвятся напрямую у Яндекса.
* **GeoDNS:** зарубежные имена теперь резолвятся «глазами выхода» (Германия/Нидерланды), а не России. Для сайтов, различающих ответы по региону, это даёт адреса, ближе к месту реального выхода (так и должно быть); российские сервисы на доменах не-`.ru` (например `.com`), которые зависят от `geoip:ru` на первом хопе, попадают в router по доменным правилам — окончательное решение «напрямую или за границу» принимает router (его DNS и списки не менялись).
* +≈100 мс на первое обращение к имени, не лежащему в кэше.
* Если `dns_server` в панели задан нестандартным адресом, `check-before.sh` остановит применение (нужен адрес с DoH и IP-сертификатом: 1.1.1.1, 1.0.0.1, 8.8.8.8, 8.8.4.4, 9.9.9.9, 149.112.112.112, либо имя узла). Сейчас в панели `1.1.1.1`.

## 5. Проверка до и после

* До: `scripts/check-before.sh` (только чтение): шаблон равен ожидаемому (sha256), сгенерированный файл равен результату шаблона (ручных правок нет), `dns_server` допустим, текущая конфигурация проходит `xray run -test -confdir`.
* После: `scripts/check-after.sh`: служба активна, нет `localhost` и есть DoH, `xray run -test` проходит, ошибок в журнале мало, **пассивный захват 15 с**: прямых DNS-запросов этого узла к 1.1.1.1/8.8.8.8/8.8.4.4/9.9.9.9 должно быть 0 (до исправления при любой активности клиентов их было >0). И ручная проверка: зарубежный и российский сайты открываются.

## 6. Откат

* Автоматический: любой сбой на шагах «проверка Xray на копии», «замена», «перезапуск», «проверка после» → файлы и служба возвращаются из копии (`/root/.claude-backups/cp09-<время>/`). Проверено: при сбое перезапуска файлы побайтно равны исходным.
* Ручной: `scripts/rollback.sh [каталог копии]` (ещё один перезапуск hiddify-xray).
* Защита от ручных правок: если шаблон или сгенерированный файл отличается от ожидаемого, пакет отказывается работать (проверено).
