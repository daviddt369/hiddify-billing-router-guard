# Аддон мульти-локаций (исходники и тесты)

Слой мульти-локаций для стека на базе Hiddify из этого репозитория: подписка предлагает **AUTO** и по одной записи на каждую настроенную **локацию**, у каждой локации свой вход и свой
балансировщик в `xray-router`, а админка управляет локациями, их нодами и общей кнопкой **«Применить»**.

Каталог - **обезличенный снимок исходников** (статус: v5). Это не готовый установщик: см. «Чего здесь нет».

## Что добавляет

| Область | Что |
|---|---|
| Подписка | `…/<ссылка пользователя>/happ/` для Happ / INCY: по одному конфигу на локацию (внутри AUTO - все протоколы, самый быстрый по пингу); обычная ссылка пользователя не меняется ни для кого |
| Router | один socks-вход и один балансировщик `leastPing` на локацию (`hutils/multiloc_router.py`); если все ноды локации недоступны - соединение закрывается |
| Админка | страница «Страны / локации» (названия, флаги, ноды, видимость, тестеры), одна панель **«Применить»** на всех страницах маршрутизации (`multiloc_apply.py`) |
| Применение | панель сравнивает router с базой и делает минимум: ничего / слой локаций / полный конвейер - в фоне, с одним перезапуском router |
| Полный цикл | старый конвейер идёт в приватной копии каталога router, его перезапуски откладываются до ОДНОГО в конце (`multiloc_full.py`) |
| Склейка правил | соседние одиночные правила с одной целью склеиваются (`router_compact.py`): маршрутизация та же, `xray -test` за 0,3 с вместо ~2 мин, старт router за секунды вместо минут |
| Заглушка `xray -test` | внутри полного цикла проверка слоёв старого конвейера (лимит 120 с) заменяется проверкой облегчённой копии |
| Удержание на решение | готовый конфиг сравнивается с рабочим ДО замены (`router_diff.py`); различия, которые правка владельца не объясняет, удерживаются, панель спрашивает («Применить новый конфиг» / «Не применять») |
| RoscomVPN в JSON | Happ / INCY получают профиль маршрутизации RoscomVPN (заголовок + правила в каждом JSON); по желанию зоны RU и банки принудительно напрямую на устройстве |
| Исправление формы | см. `release/…/commercial_routing.py` / `BusinessAdmin.py` и `tests/test_routing_form_rules.py` в корне репозитория |

## Состав

```
installer/   multiloc_installer.py (apply / rollback / verify), multiloc_delta_deploy.py (дельта по файлам с бэкапами),
             build_payload.py + formfix_pairs.py + routercore_pairs.py (точные замены в штатных файлах),
             build_manifest.py, make_diffs.py, install.sh
new-files/   файлы, которые добавляет аддон (полный текст); DESTINATIONS.md - куда они ставятся на сервере:
             panel-overlay/hiddifypanel/…, manager-scripts/ (два консольных скрипта), шаблоны haproxy / xray
diffs/       unified diff штатных / боевых файлов, которые он меняет (список - INDEX.md)
tests/       набор тестов (настоящая панель, база и xray на прод-подобном стенде) + stand_lib.py
stand-helpers/  помощники стенда: dev_redeploy.sh, run_suite.sh, run_all.sh, golden.py, perf_*.py ...
```

## Тесты

Нужен **прод-подобный стенд** (одноразовая ВМ / дистрибутив WSL с панелью, MariaDB, Redis, HAProxy, `xray`, `xray-router`): тесты ходят в настоящую панель по HTTPS, нажимают настоящие
кнопки и читают настоящий router. На голом checkout они не запускаются. Обзор: `test_01` чистые функции, `test_02` подписки, `test_03` data plane, `test_04`/`05`/`06` жизненный цикл,
миграция и установщик, `test_07` страницы, `test_09`/`13`/`14`/`15` применение и полный цикл, `test_16` поле профиля, `test_17` удержание на решение, `test_18` склейка правил
(дифф-тест двух настоящих xray на тысячах адресов), `test_19` форма маршрутизации, `test_20` исходящие upstream.
`tests/fixtures/roscom/geo/` (`geoip.dat` / `geosite.dat` RoscomVPN) не включён; файлы берутся по ссылкам из `tests/fixtures/roscom/*.DEEPLINK`.

## Чего здесь нет (намеренно)

Репозиторий публичный, а `SECURITY.md` запрещает реальные адреса серверов, домены, ключи и личные данные, поэтому в снимке **нет** журнала работ, ранбуков с деталями сервера, скриптов
разведки прода, логов, дампов базы, файлов geo-данных и полных копий штатных файлов с зашитым контактом. Несколько строк, называвших установку, заменены плейсхолдерами / нейтральным
текстом, поэтому опубликованные файлы **не побайтно равны** тому, что работает в проде (манифест и хэши не публикуются) - готовый пакет собирается из `installer/` и штатных файлов вашего сервера.
